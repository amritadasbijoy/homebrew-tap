# Homebrew tap

Homebrew casks for apps by Amrita Chandra Das.

## CoreGlance

A lightweight menu bar system monitor for Mac. [Project page](https://github.com/amritadasbijoy/CoreGlance)

```bash
brew install --cask amritadasbijoy/tap/coreglance
```

CoreGlance is not notarized by Apple, so macOS blocks it the first time you open it. Open **System Settings → Privacy & Security** and click **Open Anyway**.

To update later:

```bash
brew upgrade --cask coreglance
```
